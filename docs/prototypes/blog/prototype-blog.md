## Question
Does the Blog page work as the full list of published posts, with each whole row opening its post?

## Structure basis
The page keeps the heading, introduction, and row layout of the existing Blog page; the top navigation follows the shared header. The layout-example notice is gone because the list now holds real posts. Each row shows the date on the left, then the title and summary, and the whole row is the link. Hovering underlines the title.

Per the project capabilities, i18n and theming are disabled; both are skipped. The page has no icons.

## Demo scaffolding
The "Published posts" switch is not part of the design; do not implement it. Only the first entry is a real post; the others are mock entries that all open the same post prototype.

## Uncovered dimensions
Only the fixed light appearance and the single existing language are covered. The prototype gallery is review infrastructure, not part of the design.
