# Features

This directory describes behavior available in the current website. It is a user-facing overview, not a roadmap or implementation guide.

| Feature | Description |
|---|---|
| [Homepage](homepage.md) | Portrait, interactive dog, recent posts and app showcase. |
| [Blog](blog.md) | The list of posts and a reading page for long, figure-heavy articles. |
| [Your visitor number](visitor-counter.md) | A stable anonymous ordinal that survives refreshes. |
| [Not-found page](not-found.md) | What a visitor sees at an address the site does not have, and the way back. |
