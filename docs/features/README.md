# Features

This directory describes behavior available in the current website. It is a user-facing overview, not a roadmap or implementation guide.

| Feature | Description |
|---|---|
| [Homepage](homepage.md) | Portrait, interactive dog, recent posts, app showcase and the skills and plugins. |
| [Apps and Agents menus](nav-menus.md) | Top-navigation menus that open each app, skill and plugin, and the homepage's Agents section. |
| [Blog](blog.md) | The list of posts and a reading page for long, figure-heavy articles. |
| [Site-wide visitor total](visitor-counter.md) | Deduplicated anonymous browsers across the site, with a homepage total that updates automatically. |
| [Not-found page](not-found.md) | What a visitor sees at an address the site does not have, and the way back. |
