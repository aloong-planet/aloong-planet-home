# Site-wide visitor total

## Overview
The homepage shows the cumulative number of anonymous browsers beneath its introduction. Visitors entering through the homepage, Blog list or any published post contribute to the same total.

## Capabilities
- See “本站累计访客 N 人” on the homepage after registration completes.
- Keep the page open to receive updates every 30 seconds while visible; returning to the page refreshes immediately.
- Refresh, reopen the page or use another tab in the same browser without adding another visitor.
- Keep the same identity between the main and www website addresses.
- Continue reading when counting is unavailable; the number stays hidden until a successful update.

## Boundaries
- Cookies must be allowed. Clearing them, changing browser/device, or starting a fresh private session counts as a new visitor.
- This is a cumulative anonymous-browser count, not verified people, pageviews or currently online visitors.
- Existing visitor records remain included; previously unrecorded visits cannot be reconstructed.
- Blog pages register without showing or polling a counter. Missing pages do not register.
- Simultaneous first visits across tabs are coordinated where the browser supports it.
- The feature stores no IP address, fingerprint or browsing history.
