# App sites

> Related: [ADR-0001](../adr/0001-app-websites-in-this-repository.md) The app websites live in this repository as workspace packages, each keeping its own domain

## Problem Statement

The owner publishes a website for each app (JustSnap, Agentshed and Transfer) beside the homepage. When each site lives in its app's repository, the sites repeat the same header, breadcrumb, language handling, tests and build setup, a change every site needs is made once per repository, and the sites drift apart.

## Solution

The homepage and every app site are built, checked and deployed from this repository, each at the address it has today. Visitors see the same pages at the same addresses, and an app's repository only supplies the screenshots and the icon its site shows.

> Pending: every app site is a package under `apps/` that this repository's CI deploys.

## Functional Requirements

### app-sites::REQ-001 Every site keeps its address (direct acceptance)

The homepage is served at `https://aloongplanet.com/`, JustSnap's site at `https://justsnap.aloongplanet.com/`, Agentshed's at `https://agentshed.aloongplanet.com/` and Transfer's at `https://transfer.aloongplanet.com/`, each from this repository by the hosting that ADR-0001 sets.

### app-sites::REQ-002 Moving a site changes nothing a visitor sees

- app-sites::REQ-002/AC-01: Every address a site answered before it moved into this repository answers with the same status code after the move.
- app-sites::REQ-002/AC-02: Every page of a moved site shows, in each of its languages and appearances, the same text, images, links and layout as before the move.

### app-sites::REQ-003 Only this repository deploys the sites

- app-sites::REQ-003/AC-01: A change merged into this repository's default branch that changes a site is live at that site's address once that change's deploy has finished.
- app-sites::REQ-003/AC-02: Once a site has moved, nothing pushed to its app's repository changes what the site's address serves.

### app-sites::REQ-004 App assets arrive by pull request

- app-sites::REQ-004/AC-01: The screenshots and the app icon that an app site takes from its app change in this repository only through a pull request that the app's repository side generates. JustSnap's is generated by its release script on a Mac.
- app-sites::REQ-004/AC-02: Each app site reads its app's version and download links at run time from the app's download domain, so a release needs no change in this repository.

## Quality Requirements

### app-sites::QR-001 Narrow windows

Applies to: every page of every site this repository serves, in each of its languages.

- app-sites::QR-001/AC-01: In a window 320px wide or wider, the page does not scroll sideways: it is no wider than the window.

## Constraints

### app-sites::CON-001 A public repository whose checks are enforced (direct acceptance)

Applies to: this repository. The repository is public, and its default branch accepts only changes that have passed its required checks.

## Failure modes and boundaries

- A site's deploy fails after a change has merged: the site keeps serving its previous deploy, and the failed run is the signal; the change is not live until a deploy succeeds (app-sites::REQ-003/AC-01).
- An app releases before its asset pull request has merged: the site already offers the new version and its downloads (app-sites::REQ-004/AC-02) while still showing the previous screenshots and icon.
- During a site's move, two repositories could deploy the same address and overwrite each other: the move is complete only once the app's repository no longer deploys it (app-sites::REQ-003/AC-02).

## Out of Scope

- Transfer's mainland mirror (`transfer.aloongplanet.com.cn`): this feature does not deploy or update it; what to do about it is decided separately.
- Keeping a site's colours in step with its app's theme: each site owns its palette (ADR-0001).
- Rewriting the homepage in Astro: ADR-0001.
- Unifying the sites' interfaces, such as the Apps and Agents menus on the app sites or Agentshed's root language: decided once every site has moved, because moving a site changes nothing a visitor sees (app-sites::REQ-002).
- Moving a site from Cloudflare Pages to Workers: a separate change per site (ADR-0001).
