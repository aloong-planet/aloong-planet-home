# Specs

Each spec is the current requirement picture for one feature, for people changing that part of the site. A spec shares its slug with the page in `docs/features/`, describes the implementation as it stands, and is rewritten in place; its history is in Git.

| Spec | Feature |
|---|---|
| [Blog](blog.md) | Posts, the Blog page, and recent posts on the homepage. |
| [Anonymous visitor ordinal](visitor-counter.md) | A stable anonymous ordinal that survives refreshes. |
| [Not-found page](not-found.md) | What an address the site does not have shows, and its status. |
