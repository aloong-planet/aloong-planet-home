# Documentation layout

Current decisions and operational facts belong in docs/ops; behavior specifications in docs/specs; user-visible behavior in docs/features; approved design references in docs/prototypes; asset provenance in docs/assets. A future terminology glossary belongs in docs/CONTEXT.md and architecture decisions in docs/adr only when needed.

Construction records belong in the primary checkout under docs/.workings and are ignored by Git. They preserve execution evidence, not authoritative current behavior. External research is stored under ~/research by purpose.
